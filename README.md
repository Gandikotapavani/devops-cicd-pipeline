# End-to-End DevOps CI/CD Project

## Project Overview
This project demonstrates a hands-on DevOps workflow by building a Flask web application, containerizing it with Docker, managing source code using Git and GitHub, and deploying the application on Render.

## Technologies Used
- Python
- Flask
- Git and GitHub
- Jenkins
- Docker
- Render Cloud Platform

## Project Workflow
1. Developed a Flask web application using Python.
2. Managed source code using Git and GitHub.
3. Created a Dockerfile to containerize the application.
4. Built and ran the Docker image locally.
5. Created a Jenkins pipeline to verify Docker and build the Docker image.
6. Deployed the Flask application on Render.
7. Generated a public URL to access the deployed application.
